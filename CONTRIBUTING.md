# Contributing

Thanks for your interest in MeshVault's engine.

## Contributions need a CLA

This project is licensed GPL-3.0-only, and the owner also uses it inside a closed
product. That only works while the owner holds the copyright to all of it.

So **contributions are accepted only after you sign a Contributor License Agreement
(CLA)** that grants the owner the right to relicense your contribution. Pull requests
without a signed CLA will not be merged, however small.

If you are not ready to sign, you are still welcome to:

- open an issue to report a bug or discuss a design,
- fork the code under the GPL-3.0 and use it as the licence allows.

## Before opening an issue or pull request

- Describe the problem and how to reproduce it.
- For code, write the test first and show it failing.
- Run `cargo test`, `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check`.
